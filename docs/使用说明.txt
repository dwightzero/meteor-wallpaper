流星壁纸 · Meteor Wallpaper v1.7.1
==================================

一个纯离线的星空 / 流星雨桌面壁纸。每次启动都会随机生成一个新的星系：
一颗恒星（颜色和大小随机）、3–5 颗行星、0–2 条彗星尘埃带，
再加上一个「站在行星上看流星从天而降」的视角。
不联网、不装驱动、不改系统壁纸设置。


一、怎么用
----------
1. 把整个文件夹解压到任意位置（中文路径也可以）。
2. 双击 MeteorWallpaper.exe。
3. 桌面背景变成星空，右下角托盘出现流星图标（可能藏在 ∧ 里）。

这是绿色版：配置、日志、缓存都写在程序自己的文件夹里，
不往系统目录、我的文档里乱写（开机自启只写 HKCU 的一个 Run 项）。


二、操作
--------
右键托盘图标 → 菜单：

    开启壁纸 / 关闭壁纸
    交互模式   Ctrl+Alt+M
    视角 → 太阳系全景 / 地球视角
    换一个星系              ← 立刻换一套，不用重启
    转动一下（测试画面是否在动）
    设置…（视角、旋转速度、开机自启）
    状态…（当前种子、几颗行星、帧率、热键）
    打开数据目录
    开机自动启动
    退出

Ctrl+Alt+M（或双击托盘图标）：画面浮到最前，可以像网站那样操作
    按住左键拖动 = 旋转
    滚轮         = 拉近拉远
    Esc          = 回到桌面层

平时壁纸在桌面图标后面，收不到鼠标，也不挡任何点击。


找不到托盘图标 / 关不掉？
--------------------------
Windows 11 默认会把新出现的图标折叠进任务栏右下角的 ∧ 里，点开就能看到流星图标。
如果还是找不到，或者图标不见了：

  · 双击程序目录里的「关闭壁纸.bat」——不需要托盘，直接关掉。
  · 或者再双击一次 MeteorWallpaper.exe，弹窗里点「是」，也是关掉。
  · 实在不行：Ctrl+Shift+Esc 打开任务管理器 → 找 MeteorWallpaper.exe → 结束任务。

关掉后再双击 MeteorWallpaper.exe 就能重新开。


三、每次启动都是新星系
----------------------
· 启动时随机一个种子（seed），写进 settings.json，也显示在「状态…」里。
· 托盘「换一个星系」= 立刻重摇一次，桌面上的画面几秒内换成新的。
· 同一颗种子永远生成同一套星系。想留住现在这套：

      settings.json 里把  "keepSeed": true  然后再启动。

  改回 false 就恢复「每次启动随机」。

· 行星数量、轨道疏密、大小、配色、尘埃带、取景，全部由种子决定，
  不是随机 RGB 乱拼——颜色从预设色板里取，再按恒星色温统一偏移。


四、想要真实截图 / 诊断
-----------------------
文件夹里的几个 bat（双击即可）：
    关闭壁纸.bat      → 托盘图标找不到时，用它关掉壁纸
    截图-太阳系.bat   → 生成 preview-solar.png
    截图-地球.bat     → 生成 preview-earth.png
    诊断.bat          → 生成「诊断结果」文件夹（环境自检 + 两张截图 + 日志）

跑完把 png 或整个文件夹发我，我按你的实际画面调构图和密度。


五、常见问题
------------
Q: 双击没反应 / 托盘没有图标？
A: 图标可能藏在右下角的 ∧ 里。找不到就用「关闭壁纸.bat」关掉，再双击
   MeteorWallpaper.exe 重开。
   如果双击完全没反应，先看 data\meteor.log。最常见是缺 WebView2 运行时
   —— Win11 自带，Win10 只要装过 Edge 基本都有；还不行去微软官网装
   "Microsoft Edge WebView2 Runtime"。

Q: 桌面是黑的？
A: 同上，看 data\meteor.log 里 webview2 或 workerW 的报错。

Q: 某个星系不好看？
A: 托盘 →「换一个星系」。看不顺眼就换，不用重启。

Q: 画面太亮 / 太暗？
A: 亮度不再放进设置面板。要改就编辑 settings.json 里的
   "dim": 0.6（范围 0.2–1.0），重启生效。

Q: 想省电 / 提高帧率？
A: 设置 → 旋转速度 →「静止」最省电。
   高级：settings.json 里 "fps": 20（默认 30）。

Q: 打游戏、看全屏视频会不会掉帧？
A: 检测到全屏应用自动暂停，退出全屏自动恢复。

Q: 笔记本费不费电？
A: 默认 30fps；拔电源自动降到 20fps；锁屏自动暂停。

Q: 会挡住桌面图标吗？
A: 不会。画面在图标下面一层，图标、右键菜单、拖拽框选都正常。

Q: 多显示器？
A: 只铺主屏。

Q: 怎么卸载？
A: 托盘 → 退出（或双击「关闭壁纸.bat」）；如果开过自启，先取消勾选；然后删掉整个文件夹。
   必要时再删 %LOCALAPPDATA%\MeteorWallpaper（只有程序目录不可写时才会生成）。

七、已知限制
------------
· 只有主屏；支持 Win10 1809+ / Win11。
· 随机星系是「像那么回事」的示意，不是真实星历：
  轨道共面、尺度压缩，不能拿来算行星位置。
· 未签名的 exe 可能被杀毒软件提示，属于误报。
